# Adventure Maker
Adventure maker is a project with the purpose of refreshing my frontend skills in which i ended up implementing a backend for the security of an API_KEY but now im scalling it to include more features
## Description
Adventure maker builds you a trip based on a list of things you consider your trip must have, you can also leave comments so it takes them 
into account.
